\section*{Abstrakt}

Diese Studienarbeit dokumentiert die systematische Portierung von rund 80 Jupyter-Notebooks der Lehrveranstaltungen \enquote{Theoretische Informatik I (Logik)} und \enquote{Theoretische Informatik II (Algorithmen und Datenstrukturen)} von Python nach TypeScript. Ziel der Arbeit war es zu evaluieren, ob sich durch die statische Typisierung von TypeScript die Codequalität und Nachvollziehbarkeit in der Lehre verbessern lässt, ohne die didaktische Zugänglichkeit einzuschränken.\\
Methodisch erfolgte die Übersetzung der Lehrmaterialien durch den systematischen Einsatz \ac{KI}-gestützter Tools (wie ChatGPT und Gemini) in Kombination mit manuellen Code-Optimierungen. Da TypeScript im Gegensatz zu Python bestimmte Konstrukte wie Set-Comprehensions, Operator Overloading oder die tiefgreifende wertbasierte Gleichheitsprüfung nicht nativ unterstützt, wurden funktionale Programmierparadigmen sowie spezialisierte Bibliotheken (\texttt{z.B. recursive-set}) erfolgreich in die Jupyter-Laufzeitumgebung integriert.\\
Die Ergebnisse zeigen, dass die Portierung erfolgreich abgeschlossen werden konnte und die Notebooks uneingeschränkt im Vorlesungsbetrieb einsetzbar sind. Die didaktische Evaluierung macht deutlich, dass das strikte Typsystem von TypeScript Studierende zwar zu einer präziseren Auseinandersetzung mit Signaturen und Datenstrukturen zwingt und die anfängliche Syntax etwas komplexer wirken lässt, dadurch aber das tiefere Verständnis nachhaltig fördert. Darüber hinaus belegen quantitative Laufzeitmessungen, dass die TypeScript-Implementierungen dank der JIT-Kompilierung der V8-Engine den interpretierten Python-Originalen bei rechenintensiven Algorithmen in der Performance signifikant überlegen sind.

\section*{Abstract}

This paper documents the systematic porting of approximately 80 Jupyter notebooks for the courses \enquote{Theoretical Computer Science I (Logic)} and \enquote{Theoretical Computer Science II (Algorithms and Data Structures)} from Python to TypeScript. The aim of this work was to evaluate whether the static typing of TypeScript can improve code quality and comprehensibility in teaching without compromising didactic accessibility.\\
Methodologically, the translation of the teaching materials was carried out through the systematic use of \ac{AI}-assisted tools (such as ChatGPT and Gemini) in combination with manual code optimizations. Since TypeScript, unlike Python, does not natively support certain constructs such as set comprehensions, operator overloading, or deep value-based equality checking, functional programming paradigms and specialized libraries (e.g. \texttt{recursive-set}) were successfully integrated into the Jupyter runtime environment.\\
The results show that the porting was successfully completed and the notebooks are fully ready for use in lectures. The didactic evaluation reveals that while TypeScript's strict type system requires students to engage more precisely with type signatures and data structures, making the initial syntax appear slightly more complex, it sustainably fosters a deeper understanding. Furthermore, quantitative runtime measurements demonstrate that the TypeScript implementations, thanks to the JIT compilation of the V8 engine, significantly outperform the interpreted Python originals in compute-intensive algorithms.
